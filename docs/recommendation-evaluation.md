# 推荐算法离线评估

[返回 README](../README.md) · [当前算法与评估指南](recommendation.md)

日期：2026-10-14。该历史评估的混合算法已冻结在测试目录 `PreviousHybridRecommender`，旧类型累加算法保存在 `BaselineRecommender`，确保后续迭代不改变本报告的复现含义。完整机器可读输出见 [JSON 报告](recommendation-evaluation.json)。

## 数据与方法

使用旧项目已有的 [GroupLens MovieLens 1M](https://grouplens.org/datasets/movielens/1m/) 本地副本：1,000,209 条匿名评分。来源说明随原始数据提供；数据仅用于研究评估，不再分发，也不导入 CineMatch 的 923 部电影库。MovieLens ID 与现有电影 ID 完全独立。

- 对全部评分按时间做全局 80/20 切分，边界时间戳 `975768738` 的同秒记录全部留在训练集。
- 训练 800,168 条，测试 200,041 条；影片参考分、人数、用户画像及邻居全部仅由训练记录生成。
- 候选为训练期已出现的 3,662 部电影，排除本人训练期评分过的影片；不采样少量负例。
- 在 843 位拥有至少 20 条训练评分、至少 5 部未来高分候选的用户中，固定种子 `20261013` 抽取 100 位。测试期 4–5 星视为相关结果。
- 每人返回 12 部，比较旧算法、新版无协同分支、新版完整混合算法。相同数据、候选与排除规则。参数不依据这批留出指标调优。
- 页面验收发现实际片库同导演作品扎堆后，增加每位导演优先最多两部的约束；MovieLens 副本缺少导演字段，这项约束不影响其指标，另由单元测试验证。
- 原始文件 SHA-256 见 JSON。支持官方 `::` 格式及旧项目的逗号转换格式；使用官方原文件时校验和会不同。

## 结果

| 算法 | Precision@12 | Recall@12 | NDCG@12 | 至少命中一部的用户比例 | 片内类型多样性 | 片库覆盖率 |
|---|---:|---:|---:|---:|---:|---:|
| 旧版类型累加 | 5.58% | 1.22% | 0.0641 | 38% | 0.3904 | 7.21% |
| 新版内容分支 | 12.67% | 3.10% | 0.1508 | 59% | 0.2254 | 12.86% |
| 新版混合推荐 | 20.25% | 5.28% | 0.2239 | 76% | 0.5867 | 5.49% |

Precision 是每份推荐中相关电影的比例；Recall 是用户未来高分电影被找回的比例；NDCG 同时考虑命中及位置。命中用户比例不是“每部推荐有 76% 的准确率”。多样性为推荐两两类型集合的平均 Jaccard 距离；覆盖率为这 100 份推荐出现的不同影片占候选片库的比例。

混合算法相对旧版的用户配对 bootstrap（2,000 次、种子 42）NDCG 差值 95% 区间为 **[0.1199, 0.2006]**。最终一轮混合排序平均约 30.1 ms，P95 约 32.3 ms，仅包括进程内排序，不含数据库召回和网络，也不是生产并发压测。

## 局限与下一步

- 命中、排序和单份结果的类型多样性提升，但混合结果的片库覆盖率从 7.21% 降至 5.49%；跨用户推荐更集中。后续验证及保留默认排序的决策见 [探索模式评估](recommendation-discovery-evaluation.md)。
- 纯内容分支的类型多样性低于旧版，不声称所有场景都已改善。没有其他用户评分时，实际项目会使用这个内容分支，加上导演约束与用户主动反馈。
- 这是较早期 MovieLens 用户上的回顾性测试，抽样的是有历史评分且在测试期继续活跃的用户。结果不能直接等同于当前中文片库、冷启动用户或线上满意度。
- 数据缺少导演、国家及本站主动偏好；这些信号与隐藏反馈通过规则测试和真实片库交互验收，不用 MovieLens 指标冒充其效果。
- 当前没有把历史用户导入线上，实际协同分支需要本站积累足够的共同评分后才会生效。

## 复现

将已取得使用许可的 MovieLens 1M 数据放在本地任意目录，提供 `ratings.dat` 和 `movies.dat`：

```sh
bash scripts/mvn.sh -Dtest=RecommendationEvaluationTest \
  -Drecommendation.evaluation.data=/absolute/path/to/ml-1m test
```

输出为 `backend/target/recommendation-evaluation.json`。不配置路径时该大型评估自动跳过，普通单元与 API 测试照常执行。评估不连接数据库、不使用用户画像文件、不写入账号或评分。
