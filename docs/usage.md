# CineMatch 页面操作与执行步骤

[返回 README](../README.md) · [部署与启动](deployment.md) · [推荐算法与评估](recommendation.md)

先按部署文档启动程序。开发页面在 `http://127.0.0.1:5173`，完整 JAR 页面在 `http://127.0.0.1:8080`；以下页面路径拼到所用地址之后即可。本文是可重复执行的操作说明，实际已完成的检查另记于 [验收记录](verification.md)。

## 1. 游客浏览电影

1. 打开首页 `/`，通过搜索框查找电影，使用类型和排序选项缩小范围，翻页浏览。
2. 点击电影卡片进入 `/movie/电影ID`，查看简介、导演、年份、片长、参考评分、来源及相似电影。
3. 打开 `/sources` 查看数据来源说明。外部历史参考分、演示评分和自己的 1–5 星评分含义不同。
4. 进入 `/picks`，无需注册即可按类型与时长找电影。游客的筛选不会生成账号或保存个人画像。

初次安装只有 18 部样例，筛选后可能很少；扩充资料见 [目录导入步骤](deployment.md#7-扩充电影目录)。系统提供资料与推荐，目前没有电影在线播放、下载或购票功能。

年份区间和片长上限可与所有电影类型、关键词组合，点击“应用筛选”生效；条件写入 URL，刷新保留。首页专题由管理员配置，其入口应用相应筛选条件。

## 2. 注册、登录与设置个人偏好

1. 从页面账号入口打开注册表单，填写账号、昵称和密码。账号为 3–32 位字母、数字或下划线，保存时转为小写；昵称最多 40 个字符；普通账号密码 8–72 个字符，且最多 72 个 UTF-8 字节。
2. 登录后打开 `/profile`，修改昵称、简介（最多 280 个字符）和长期偏好（最多 8 种电影类型），保存。
3. 刷新页面确认资料仍在；头像菜单可退出登录。应用重启后可能需要重新登录。

用户名不支持在个人中心修改，当前没有头像上传、找回密码或账号注销入口。偏好用于推荐加权，不意味着只展示这些类型。

## 3. 想看、看过与评分

1. 打开任意电影详情，点击“想看”，再进入 `/library` 的想看分类核对。
2. 看完后可标记“看过”，或者直接保存 1–5 星评分和可选短评（最多 2,000 字符）。保存评分会同时标记看过。
3. 在详情、片单或个人中心编辑自己的评分与短评。电影详情的公开短评展示最近 20 条非空文字评论，仅打星不会生成一条空白公开评论。
4. “移出片单”只移除想看 / 看过状态，已有评分和短评保留；在片单“已评分”或个人中心仍可找到。
5. 单独删除评分与短评不会删除片单状态。若电影仍在“看过”列表，它依旧会计入观影统计并从推荐中排除。

个人评分不会覆盖电影的外部参考分，也不会被算作外部数据源的评分人数。

## 4. 片单批量管理

在 `/library` 切换全部、想看、看过、已评分。搜索支持片名、原片名与导演；排序支持最近更新、我的评分、电影名称，每页展示 24 部。

1. 勾选电影，或选择本页全部，最多选中 100 部。
2. 使用批量“想看”“看过”“移出片单”。单次批量请求会先校验所有电影，再在同一事务中写入。
3. 操作后可撤销当前页面记录的最近一次片单变更。撤销不是永久操作历史，刷新或离开页面后不能依赖它恢复。
4. 移出后若仍有评分，到“已评分”分类查找；“全部”只列当前在片单中的电影。

想看 / 看过与“自定义片单”是两套独立管理：前者记录观影状态，后者按主题组织电影。在“我的片单”右上进入 `/collections`：

1. 点击“新建片单”，填写名称和介绍。每个账号最多 50 个片单，每单最多 1,000 部电影。
2. 在片单中搜索并多选电影添加，或从详情页、片单批量操作中加入。重复添加不会生成重复条目。
3. 为影片保存独立备注；点击上下箭头排序，选择其中一部作为封面。长片单按服务端分页加载。
4. 使用“编辑片单”修改名称和介绍，“导出 JSON”下载完整片单与影片资料，导出不受当前分页限制。
5. 移出影片或删除合集不删除想看 / 看过状态、评分或其他合集内容。合集仅本人可见，URL 不是公开分享链接；目前不提供 JSON 反向导入和多人协作。

自定义合集本身不作为推荐偏好信号，也不会自动将影片标记为想看。需要影响推荐时使用想看、看过、评分或个人偏好。

## 5. 使用推荐与反馈

打开 `/picks`：

| 操作 | 实际效果 |
|---|---|
| 为你精选 | 默认融合个人内容偏好、口碑和满足条件的邻域评分 |
| 探索发现 | 在部分位置尝试较少人评价、满足质量与相关性门槛的电影 |
| 类型筛选 | 最多选 3 种，匹配任意一种即可；本次选择替代长期类型偏好参与本次推荐 |
| 观影时长 | 不限、90 / 120 / 180 分钟以内；指定上限后排除未知片长 |
| 下一组 / 上一组 | 当前页面内避免重复、返回已缓存结果；最多累计展示 120 部 |
| 不感兴趣 / 不再推荐 | 登录后将该电影加入个人隐藏列表；不会删除电影、片单或评分 |

推荐默认排除已在片单、已评分和已隐藏的电影。换一组只是本次临时排除，不等于“不感兴趣”。模式、类型和时长保存在 URL，分享地址不会共享私人资料或本页批次历史；刷新、切换条件或更新观影记录后重新开始批次。

在 `/profile` 的“不再推荐”区域可恢复隐藏电影。恢复只解除这项排除，电影仍可能因已评分、片单或筛选条件而不出现在当前推荐。

刚注册时可以先选偏好，再为确实看过的电影打分；邻域协同需要多位本站用户有足够共同评分，单个账号即使评分较多也不保证会出现“与你评分相近的影迷也喜欢”。筛选后候选不足时返回少于 12 部是正常情况。

## 6. 查看个人中心

`/profile` 提供资料、偏好、观影统计、评分短评和隐藏记录的集中管理。

- 看过数量来自当前片单中标记为看过的电影。
- 观影时长按这些电影的片长求和，不记录重复观看次数或实际播放时长。
- 我的平均评分来自本人保存的星级，已移出片单但保留的评分仍参与平均值。
- 类型分布按看过的电影统计，一部电影可能同时计入多个类型。

个人中心的“推荐效果观察”可暂停新的观察记录，也可清除历史观察；两者不会删除片单或评分。评分历史按服务端分页加载，统计仍覆盖全部本人记录。

## 7. 管理员维护目录

先按 [管理员初始化](deployment.md#5-初始化管理员) 创建管理员，再登录进入 `/admin`。

1. 查看电影、用户、评分短评、片单条目数量概览。
2. 搜索或翻页定位电影；添加、编辑资料，设置首页甄选。海报与背景填写 HTTPS 地址或已有 `/images/` 路径，当前没有上传界面。
3. 保存后到首页和详情核对字段与图片。人工维护过的电影会被后续公开目录自动更新跳过。
4. 用户概览显示最近 100 个账号的公开字段与角色，只读，不能在此新增、删除、封禁用户或更改角色。

删除电影会清理关联片单、评分和隐藏反馈，应仅对确认不再保留的条目操作；验证删除功能时使用自己新建的测试电影。普通用户的菜单没有内容管理入口，后端也会拒绝访问受保护的管理 API。

管理员的“首页专题”页支持创建、编辑、启用、排序和删除专题，配置类型、年份与片长条件。“推荐观察”页按 7 / 30 / 90 天、版本、模式及用户分组展示曝光、点击、收藏和评分；无曝光时比率显示空值而非 0。含义见 [本站推荐观察](recommendation-observation.md)。

## 8. 一次完整的功能验收

在独立测试库或专用测试账号执行以下顺序，避免修改日常使用记录：

| 顺序 | 操作 | 预期结果 |
|---|---|---|
| 1 | 游客搜索、筛选、详情刷新 | 页面可访问，结果符合查询；直达详情无需先打开首页 |
| 2 | 注册、登录、保存个人偏好后刷新 | 资料保存成功，身份正确 |
| 3 | 添加想看、批量看过、撤销 | 分类计数与电影状态同步变化 |
| 4 | 保存评分，再移出片单 | 已评分和个人中心仍可管理该记录 |
| 5 | 切换推荐模式和条件，换一组再返回 | 条件生效，当前批次不重复，上一组可返回 |
| 6 | 隐藏推荐电影，再到个人中心恢复 | 隐藏期间推荐排除，恢复后解除隐藏限制 |
| 7 | 退出并换另一个测试账号登录 | 看不到前一账号的私人片单、资料和隐藏记录 |
| 8 | 管理员维护一部测试电影 | 首页 / 详情同步更新，普通用户不能调用管理接口 |
| 9 | 停止并重新启动同一数据目录的应用 | 重新登录后电影与私人记录仍保留 |

这些步骤验证功能闭环；推荐是否更准确需使用独立的 [离线评估方法](recommendation.md#8-评估与复现)，不能从一次页面体验推断。

## 推荐实验室与模型后台

打开 `/picks` 查看观影指纹与真实模型状态，登录后点击“建立我的观影指纹”，为看过的电影保存评分。至少 3 部活动模型覆盖的评分可启用协同分支；继续评分、修改评分都会重算下一次推荐。类型雷达统计已评分电影分布，不是预测准确率；卡片“协同发现”表示该电影排序实际使用了模型分。

管理员在“推荐模型”中选择已准备的数据集、训练、查看进度、启用、回退或导出版本；详见 [模型操作指南](recommendation-models.md)。
